# Emanate AI

Single-page marketing site for Emanate AI — local SEO and automation for
Adelaide and Fleurieu Peninsula businesses.

Static HTML, no build step. `index.html` is the whole site.

## Editing

Open `index.html`. Copy lives in the HTML, colours live in the `:root`
block at the top of the `<style>` section.

## Deploying

Connected to Vercel. Pushing to `main` deploys automatically.
